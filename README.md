# Licitaciones MX — LicitIA Labs

Panel web estático para explorar oportunidades demostrativas de contratación pública en México y acceder a fuentes oficiales.

## Publicación en GitHub Pages

1. Elimina del repositorio el archivo incorrecto llamado `mkdir licitaciones-mexico-panel cd licitaciones-mexico-panel git init`.
2. Sube todo el contenido de esta carpeta a la raíz de la rama `main`.
3. En **Settings → Pages**, selecciona **Deploy from a branch**, rama `main` y carpeta `/ (root)`.
4. Espera unos minutos y visita `https://licitia-labs.github.io/licitaciones_mx/`.

## Alcance

Los registros incluidos son ejemplos y no licitaciones vigentes. Para automatizar datos reales se requiere integrar una fuente autorizada y un proceso de actualización.
